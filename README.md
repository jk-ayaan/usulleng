# 📮 우슐랭 · 우체국 맛집 가이드 (부산·울산·경남)

부산지방우정청 **「우체국 추천 맛집가이드」**(발행일 2024.05)의 **245곳**을 지도·검색·필터로 둘러보는 모바일 반응형 웹앱.

> 데이터 출처: 부산지방우정청 「우체국 추천 맛집가이드」 공식 전자책자 (발행일 2024.05) · 부산·울산·경남 37개 우체국 직원·집배원 추천

'우슐랭'은 **우체국 + 미슐랭**의 합성어로, 매일 골목을 다니는 집배원과 지역에 밝은 우체국 직원이 직접 추천한 '로컬 맛집'을 모은 가이드입니다.

## 규모

| 지역 | 곳수 |
|---|---|
| 부산 | 95 |
| 울산 | 20 |
| 경남 | 130 |
| **합계** | **245** |

## 기능

- 🗺 **지도** — Leaflet + OpenStreetMap(CARTO), 클러스터, 핀 클릭 시 정보 팝업
- 🏷 **지역 탭** — 부산·울산·경남·전체 (기본 부산)
- 🔎 **검색** — 식당명·메뉴·지역·추천 우체국
- 🍽 **필터** — 음식종류(고기·국밥탕·회·면 …) + 구·군/시
- ↕ **정렬** — 기본·가나다·거리순 + 📍 내 위치 반경(1·3·5·10km)
- 🃏 **카드** — 추천 우체국 뱃지, 메뉴/가격, 주소, 영업시간, 전화·카카오맵·네이버 길찾기

데이터가 내장된 **단일 `index.html`** 로 서버 없이 열어도 동작합니다.

## 데이터 파이프라인

```bash
# 1) 공식 PDF 파싱 → data/restaurants.json  (parse 완료, 좌표·분류 포함)
# 2) 주소 → 좌표 (Kakao Local API)
KAKAO_REST_KEY=발급키 python3 geocode.py
# 3) 빌드
python3 build.py            # data/restaurants.json → index.html
```

| 파일 | 설명 |
|---|---|
| `build.py` | data → 단일 HTML(지도·필터·검색) 생성기 |
| `geocode.py` | 주소 → 좌표 (Kakao Local, 주소→키워드 폴백·캐시) |
| `make_icon.py` · `make_icon2.py` | 투톤 앱 아이콘(SVG→PNG) 생성기 |
| `data/restaurants.json` | 245곳 데이터셋 (이름·우체국·종류·메뉴·주소·전화·영업시간·좌표) |
| `icon/final/` | 앱 아이콘 세트(편지봉투+Food 투톤) + favicon |

## 주의

공개 자료를 정리한 것으로 실제와 다를 수 있습니다. 방문 전 영업시간·휴무를 확인하세요. 음식종류는 이름·메뉴 기반 **자동 분류**이며, 좌표 일부는 도로/동 단위 근사일 수 있습니다. **2026 개정판(240곳)** 은 공식 전자책자 공개 시 갱신 예정입니다.
